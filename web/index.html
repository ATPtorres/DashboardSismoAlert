DETENIDA

Puedes cambiar de escenario mientras la simulación está activa. El panel principal reflejará el cambio en tiempo real.

¿Qué puedes probar?

  • Reposo: lectura estable y enlace vigente.
  • Anomalía: incremento artificial de vibración y aviso visual.
  • Falla de sensor: detección no disponible.
  • Pérdida de enlace: datos vencidos y nodo sin comunicación.
  • Calibración / perfil: estados de configuración del sensor.

La simulación se ejecuta únicamente en esta pestaña. Al detenerla, se descartan sus muestras y avisos temporales.

Un monitor experimental, con límites claros.
Qué significa una anomalía
Una vibración bajo el criterio configurado. No demuestra un sismo, una magnitud, un epicentro ni seguridad estructural. NORMAL tampoco significa «edificio seguro».
La señalización es autónoma
El emisor decide; el receptor maneja LEDs y buzzer. Cerrar un aviso solo lo oculta en esta pantalla. Una pestaña suspendida no garantiza avisos.
Continuidad local
Sin API o MySQL se suspenden cuentas, permisos e historial. El resumen de contingencia deberá servirse desde el ESP32. En este entorno el receptor aún no está integrado.
Ubicación y alcance
Las coordenadas son configuradas, no GPS. Un radio visual no representa alcance del sensor ni cobertura. Ruta autorizada y punto de reunión: no configurados, pendientes de verificación.
